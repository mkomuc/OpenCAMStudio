# Open CAM Studio icon concept

Created with the built-in image generation tool. This is a new icon concept;
the existing application icon and packaging references remain unchanged.

- `open-cam-studio-source.png`: original generated image with transparency.
- `open-cam-studio-1024.png`: 1024 × 1024 PNG.
- `OpenCAMStudio.icns`: macOS icon with standard and Retina sizes.
- `OpenCAMStudio.iconset/`: PNG sizes used to build the macOS icon.

Resized with macOS `sips` and packaged as an ICNS container with PNG entries.

## Generation prompt

Use case: logo-brand
Asset type: Desktop application icon for "Open CAM Studio", a professional CNC machining and toolpath application.
Primary request: Create one polished, distinctive app icon. A compact silver CNC end mill above an isometric machined aluminum workpiece; a bold cyan open circular pocket/toolpath forms the main graphic on the workpiece. The open ring subtly evokes a C. Toolpath and cutter should read as one coherent, simple emblem.
Style: beautifully restrained dimensional industrial design, precise bevels, satin aluminum, crisp silhouette, subtle studio highlights. Premium native desktop app icon, not a photoreal scene. Use broad simple forms readable at 32 pixels.
Composition: centered emblem on a deep graphite rounded-square tile, straight-on tile with isometric object inside. Tile fills about 88% of a square 1024x1024 canvas with generous safe margin. Everything contained inside the tile. Transparent canvas outside the tile.
Color palette: graphite, cool silver and vivid cyan #4cc9f0, matching the application's existing palette.
Constraints: one icon only; no text, no letters, no labels, no watermark, no extra props, no grid, no elaborate machinery, no tiny details. Keep strong figure-ground contrast and clean smooth edges.
