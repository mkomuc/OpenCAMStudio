This release includes the v0.3.0 feature update and fixes escaped-line STEP import for Windows-style line endings.

## Highlights

- Fourth-axis rotary wrap milling, rotary simulation, and operation previews.
- Multiple-depth controls and contour roughing passes for profiles and chamfers.
- Numeric expressions for operation parameters and measurements in the 3D view.
- Pocket clearing with multiple features per operation and stock contours.
- Setup fixtures, safer profile routing, and machine spindle, feed, and Z limits.
- Improved adaptive cutting links, pocket leads, operation defaults, and simulation caching.
