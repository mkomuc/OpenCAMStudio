## What's new

- Added fourth-axis rotary wrap milling, rotary simulation, and operation previews.
- Added multiple-depth controls and contour roughing passes for profiles and chamfers.
- Added numeric expressions for operation parameters and measurements in the 3D view.
- Expanded pocket clearing with multiple features per operation and stock contours.
- Added setup fixtures, safer profile routing, and machine spindle, feed, and Z limits.
- Improved adaptive cutting links, pocket leads, operation defaults, and simulation caching.
